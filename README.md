# Dermis

Landing de Dermis: una página para presentar el proyecto, sumar gente a la waitlist y recibir ideas de la comunidad.

Dermis analiza dos fotos de tu rostro y arma tu rutina de skincare (limpiar, tratar y proteger) con productos reales según sus ingredientes activos y tu presupuesto. También muestra el costo de la rutina y una racha para que mantener el hábito sea más fácil.

## Qué incluye la página

- Presentación del proyecto y cómo funciona.
- Formulario de waitlist (nombre, correo e intereses).
- Formulario de ideas para mejorar Dermis.
- Sección para dermatólogos/as que quieran sumarse.

## Tecnología

Es una página estática (`index.html`, un solo archivo con HTML, CSS y JS). Los envíos de los formularios se guardan en una hoja de cálculo del equipo mediante un pequeño script de Google Apps Script.

Está publicada con GitHub Pages.
